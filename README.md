# SportsClubManager

A small college sports club management project created as a Git and GitHub laboratory exercise.

## Project contents

- `players.txt` - sample player records
- `coaches.txt` - coach list
- `tryouts.txt` - player selection process
- `tournament_rules.txt` - tournament rules
- `schedule.txt` - winter schedule information
- `certificates/` - directory reserved for player achievement certificates
- `.gitignore` - ignores log files and temporary score data

## Git concepts demonstrated

This repository demonstrates local repository setup, commits, `.gitignore`, empty-directory tracking with `.gitkeep`, branching, merging, conflict resolution, stashing, lightweight and annotated tags, rebasing, GitHub hosting, and GUI workflows with GitHub Desktop and VS Code.
